# Astra capability ledger

Source baseline: commit `051e62ed742a12ae7f25a4e4c4a39fe6eb9d1ffb`, inspected 1 October 2026. The installed Xcode MCP resolved the app scheme to `astra`, destination `My Mac`, with macOS 27.0 and iOS 27.0 deployment targets. The app-only build succeeded. These findings describe source and public API boundaries; no app, website, provider, hardware, or signed release was run.

## Baseline reconciliation

The shared `astra` scheme named the `astraInfrastructureTests` target, while the target's `astraInfrastructureTests/` source directory was absent. This snapshot also contains no browser fixtures, fixture server, or `scripts/release/` helpers. The two committed release workflows remain and reference those missing helpers. The app scheme built successfully before cleanup; this did not compile or execute the missing hosted tests. Task 00 removes only the stale test target and scheme reference. It does not recreate deleted test, fixture, or release assets.

Xcode also lists an `AstraWatch` shared scheme, but its buildable reference has no corresponding project target. The empty Watch scheme was not changed because the baseline packet only repairs the missing hosted-test target.
